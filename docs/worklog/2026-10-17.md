## Исправление пустых ответов

Симптом: «Не удалось сформировать ответ. Попробуйте уточнить запрос» даже на
простой вопрос. Реальная диагностика показала успешный `response.completed`
с пустым `output`, хотя данные приходили отдельными событиями потока.

- В `PlanClient.create` добавлен сбор `response.output_item.done` по output_index.
- Если финальный output пуст, он восстанавливается из завершённых элементов.
- Сохраняются текст, function calls и encrypted reasoning для следующих запросов.
- Ответ считается успешным только после completed; failed/incomplete/обрыв
  не превращаются в успешный ответ из частично полученных данных.
- В check.py строковый input заменён на массив сообщений; добавлена проверка
  непустого текста диагностического ответа.
- Добавлен регрессионный тест на реальном SDK с замоканным SSE-транспортом.
- 13 тестов прошли. Реальный запрос `17 × 23` вернул 391.
- Пользователь подтвердил исправление в Telegram.

## Telegram-форматирование

Симптом: Markdown вроде `**слово**` отображался со звёздочками.

- Добавлен assistant/formatting.py и зависимости markdown-it-py 4.0.0, mdurl 0.1.2.
- Markdown преобразуется в текст и Telegram MessageEntity; HTML parse_mode
  не используется, сырой HTML остаётся текстом.
- Поддержаны жирный, курсив, зачёркивание, ссылки, заголовки, списки, цитаты,
  inline code и блоки кода с языком.
- Длинные сообщения делятся с учётом UTF-16 и эмодзи; entities пересчитываются.
- Выделения разделяются вокруг кода, чтобы избежать запрещённых пересечений.
- Календарные названия и ошибки отправляются буквально, без Markdown-парсинга.
- Клавиатура подтверждения остаётся у последнего фрагмента.
- 21 тест прошёл локально и на VPS. Через Telegram отправлено диагностическое
  сообщение, ответ API подтвердил ожидаемые entity types.
- Пользователь подтвердил корректный вид новых ответов. Старые сообщения не менялись.

  автоматическую передачу распознанного текста и единое сообщение с ответом.
- Реальные запросы через Agent подтвердили поиск Tesla с URL, прогноз погоды
  Минска с источниками и чтение завтрашних встреч Outlook. В проверке запись
  календаря была запрещена; рабочая история не менялась.
- Для поиска запрашивается `web_search_call.action.sources`; сохранён
  `reasoning.encrypted_content`. Если ответ не содержит URL-аннотаций, доступны
  ссылки из метаданных поиска. Встроенные источники типа api без URL не превращаются
  в выдуманные ссылки. Сериализация новых типов источников не печатает их в логи.

## Личный стиль общения

По просьбе владельца добавлена загрузка постоянных предпочтений из
`DATA_DIR/persona.txt` при запуске. Профиль применяется к каждому запросу,
включая голосовые, и сохраняется после `/reset`. Сам текст хранится вне Git.
39 тестов прошли на Mac и VPS. Профиль установлен на сервер с владельцем
telegram-assistant и правами 600. После перезапуска службы реальный короткий
запрос через Agent подтвердил применение профиля к ответу. Тест использовал
временную SQLite и не менял рабочую историю.
