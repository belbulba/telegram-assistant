# Журнал работы — 18 октября 2026

## Прототип заметок Outlook

Добавлен и проверен прототип создания через Microsoft Graph `/me/notes`
(коммит 231111e, 43 теста прошли локально и на VPS). Авторизация выполнялась
в отдельный `data/msal-notes-pending.json`; рабочий MSAL-кэш не заменяли,
службу с новым инструментом не перезапускали.

После повторного согласия и принудительного обновления токена ответ Microsoft
подтвердил `ShortNotes.ReadWrite` и `Calendars.ReadWrite`, однако чтение заметок
вернуло HTTP 403 `ErrorAccessDenied`. Предыдущая попытка создания также получила
403. Успешно созданных тестовых заметок нет. Это не было исправлено добавлением
разрешения в Entra. Аналогичный случай личного Outlook описан в Microsoft Q&A:
https://learn.microsoft.com/en-us/answers/questions/6017164/get-me-notes-returns-403-erroraccessdenied-for-a-p

По просьбе владельца прототип Outlook Notes удалён. Календарная интеграция
возвращена к прежнему поведению. Выданное согласие Microsoft и отдельный файл
авторизации этим удалением кода автоматически не отзываются.

## Следующее направление: Gmail

Владелец хочет заметки в разделе Google стандартного приложения «Заметки»
iPhone, а также чтение, сортировку, отметку прочитанного и удаление ненужных
писем. Подключение Gmail к серверу пока не выполнено. Сначала проверить одну
запись специального почтового формата в Notes и её появление на iPhone.
Недостаточно просто назначить произвольному письму ярлык Notes.

Для прототипа и почтовых операций планируется Gmail API с OAuth
`gmail.modify`: чтение, ярлыки, прочитанность, перемещение в корзину и вставка
сообщений. Безвозвратное удаление не требуется. Отдельный доступ Google боту
нужен даже при подключённом Google-аккаунте на iPhone или в ChatGPT.

## Gmail OAuth и заметки — подключение

Настроен Desktop OAuth через официальную google-auth-oauthlib, loopback callback,
PKCE, gmail.modify и offline refresh token. JSON клиента и токены остаются вне
Git, права 600. Локальные запросы profile и labels успешны. Тестовая MIME-запись
с com.apple.mail-note и ярлыком Notes создана через Gmail API. Пользователь
подтвердил появление на iPhone: «работает как часы».

Добавлен create_note в Agent при наличии Gmail-авторизации: текст и голос
используют один инструмент. HTML экранируется, переносы строк сохраняются.
Повтор одинаковой записи в одном ходе запрещён, включая неопределённый результат.
Почтовые операции чтения, сортировки и корзины остаются следующим этапом.
